# Voice

Rules for every string people read in the portal and the tray menu. Use the words in [glossary.md](glossary.md).

1. Say what the user gets before how it works.
2. Say "you" and name the thing. Never "it" or "its" for a device the sentence has not named.
3. One idea per sentence, under 20 words. No clauses joined by a colon.
4. Buttons are a verb and a noun: "Add device", "Create exit". Never "Make".
5. An error says what happened and what to do next.
6. No internal words: stage, daemon, connectd, slot, bridge, policy keys. Commands go behind "How to fix".
7. A state is one or two words: "On", "Off", "Waiting for exit".
8. Sentence case everywhere.

## Before and after

| Today | Write instead |
| --- | --- |
| The move could not be said: try again. | Couldn't move it. Try again. |
| None — the usual way out | No exit (direct) |
| Off — traffic goes its usual way | Off |
| Made. Now choose the devices that run it: each goes into service once its checks pass. | Exit created. Choose the device that will carry its traffic. |
| Reaches what it may by name and address, without starting a connection | Lets this device reach your other devices by name. |
| In this browser — nothing to install | Open in browser |
| Blocked — held by the device's admin | Updates are paused on this device |

The wording test counts English strings longer than 25 words and strings with stage, daemon, connectd or sudo. Neither count may rise.
